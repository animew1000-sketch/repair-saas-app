🏢 Multi-Tenant SaaS Architecture

Instantly onboard auto repair businesses with individual branding, custom theme colors, dedicated URLs, and isolated database schemas.

⚡ Staff 6-Digit PIN System

Technicians and service advisors log in within seconds via shop-assigned PINs, eliminating complex passwords on the shop floor.

✉️ Client Portal & Status Tracking

Vehicle owners receive live job status updates, view digital repair estimates, and review transparent invoices from any device.

🔍 Integrated VIN & Parts Lookup

Automated 17-digit VIN decoding matches vehicle makes and models with real-time market pricing for parts and labor billing.

🎯 Ready-to-Present Project Architecture

This software solution demonstrates a production-grade Web Application featuring Node.js Express API endpoints, MySQL multi-tenant database normalization, JWT authentication with role-based access control (RBAC), and custom frontend CSS variable theme synchronization.
